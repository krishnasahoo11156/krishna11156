## Problem Statement
Standard task managers function as static, passive to-do lists that fail to warn users of upcoming schedule conflicts or actively rescue slipping deadlines before they fail.

## Solution
Built **ForeSee** — an AI-powered predictive deadline rescue platform that continuously evaluates calendar slots, simulates alternative paths using Monte Carlo trials, and automatically reschedules tasks on Google Calendar via Gemini-based multi-agent orchestration.

## Technologies Used
- **Frontend:** Next.js 14, Tailwind CSS, TypeScript
- **Backend:** Node.js, Express, Docker, Google Cloud Run
- **Database & Auth:** Firebase Firestore, Firebase Auth (Google OAuth2)
- **AI & Reasoning:** Google Gemini API (2.5 Pro & Flash)
- **Messaging backbone:** Google Cloud Pub/Sub
- **Integrations:** Google Calendar API, SendGrid API
- **Deployment & Security:** Google Cloud Build, Cloud Secret Manager
