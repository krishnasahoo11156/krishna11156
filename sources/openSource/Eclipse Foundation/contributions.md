Eclipse Foundation

> **Ideal for Java tooling, IDE development and enterprise software.**

## 📖 About

The Eclipse Foundation develops and maintains some of the most widely used Java technologies including the Eclipse IDE and Jakarta EE. It is an excellent organization for developers interested in IDEs, developer tools, enterprise Java and cloud technologies.

**Tech Stack**
- Java
- Maven
- Gradle
- OSGi
- SWT
