# 3. Jenkins

> **Best organization for learning CI/CD and enterprise Java development.**

## 📖 About

Jenkins is one of the world's most popular automation servers used for Continuous Integration and Continuous Deployment (CI/CD). Its ecosystem contains thousands of plugins and provides an excellent learning environment for Java developers.

**Tech Stack**
- Java
- Maven
- Groovy
- Docker
- Git
