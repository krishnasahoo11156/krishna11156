# 4. OpenMRS

> **One of the most beginner-friendly GSoC organizations.**

## 📖 About

OpenMRS is a global open-source Electronic Medical Record (EMR) platform used in healthcare systems worldwide. It is well known for welcoming first-time contributors and consistently participating in Google Summer of Code.

**Tech Stack**
- Java
- Spring Boot
- Hibernate
- MySQL
- REST APIs
