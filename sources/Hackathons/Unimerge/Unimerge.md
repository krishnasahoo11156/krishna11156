### Project Name
**StudySync**

### Problem Statement
Students struggle to stay focused and organized due to fragmented academic tools, losing efficiency when switching between separate task planners, calendar apps, file managers, and ambient sound timers.

### Solution
StudySync is a unified React-based academic command center that integrates real-time task management, a conflict-detecting calendar, a folder-structured PDF vault, and a custom Pomodoro timer with procedural ambient soundscapes into a single premium workspace.

### Technologies Used
- React.js (Vite)
- Tailwind CSS
- React Router
- Web Audio API (procedural audio synthesis)
- Firebase Authentication
- Cloud Firestore (NoSQL database)
- Firestore Base64-to-JSON Storage Strategy

### Your Contribution
- **Designed Software Architecture:** Structured the React frontend modules and designed the NoSQL schema for users, tasks, library folders/files, and user focus preferences in Cloud Firestore.
- **Built Frontend UI/UX:** Developed the responsive React application using a custom "Luminous Organicism" glassmorphic UI design system with soft-green palettes, frosted panels, ambient shadows, and micro-animations.
- **Implemented Calendar & Library Modules:** Developed the conflict-detecting intelligent calendar and created the hierarchical cloud storage library using a zero-CORS Base64-to-Firestore encoding strategy.
- **Built Pomodoro & Audio Engine:** Developed a customizable Pomodoro timer and built a programmatic ambient synthesizer utilizing the Web Audio API to generate custom soundscapes (Rain, Birds, Café, Library, White Noise) natively without external files.
