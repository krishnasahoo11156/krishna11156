One-Line Tagline
Code2Git — Effortlessly sync your coding platform solutions to GitHub and build your developer portfolio in real-time.

Short Description (2–3 lines)
Code2Git is a secure, client-side Chrome extension that automatically commits accepted solutions from LeetCode, Codeforces, and GeeksforGeeks to your GitHub repository. By eliminating manual copy-pasting, it helps competitive programmers and software engineering students showcase their consistency and build a polished developer portfolio while keeping all credentials completely private.

What problem it solves: Eliminates the tedious manual copy-pasting of coding solutions to GitHub, while keeping credentials completely secure and client-side (no middleman servers).

Who it's built for: Competitive programmers, students, and job seekers practicing on LeetCode, Codeforces, and GeeksforGeeks who want to automatically build a portfolio.

Tech Stack: JavaScript (ES6), HTML5, CSS3, Chrome Extensions API (Manifest V3), GitHub REST/GraphQL APIs, and optional Firebase Realtime Database.

Here are the key features:

Automatic Real-time Sync: Instantly detects and uploads accepted solutions from LeetCode, Codeforces, and GeeksforGeeks to your GitHub repository.
100% Client-Side Security: Stores credentials and access tokens locally in the browser, eliminating external server hops.
Interactive Statistics Dashboard: Tracks solved problems, platform distributions, and submission history in a visually rich dashboard.
Flexible Authorization: Connects to GitHub seamlessly using either secure OAuth Device Flow or a Personal Access Token (PAT).
Private Coding Leaderboards: Connects to a custom Firebase URL to share stats and compete on private leaderboards with friends.

Here is the **Impact** of the project:

* **Saves Hundreds of Manual Hours:** Automates a tedious, repetitive workflow, allowing developers to focus 100% of their energy on learning and solving problems rather than managing files.
* **Boosts Developer Profile Visibility:** Transforms an inactive GitHub graph into a vibrant showcase of consistent problem-solving and algorithmic skills, making developers stand out to tech recruiters.
* **Fosters Consistency Through Gamification:** The built-in dashboard and private peer leaderboards gamify practice, encouraging students to build healthy, daily coding habits.
* **Sets a High Standard for Security:** Demonstrates that productivity tools do not need to compromise privacy, proving that complete automation can be achieved with a zero-server, zero-trust client-side architecture.
